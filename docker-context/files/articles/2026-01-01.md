### Text Processing

- `awk '{print $1, $2}' <file>`
  - Extract fields from a file or command output, separating by whitespace (use `-F` for a different delimiter)
  - `awk -F ":" '{print $1}' /etc/passwd` to extract usernames
  - `awk '{sum += $1} END {print sum}' <file>` to sum values in a column
  - `awk 'NR==5' <file>` to print the 5th line
  - `awk 'NR>=5 && NR<=10' <file>` to print lines 5 to 10
  - `awk '/pattern/ {print $0}' <file>` to filter lines matching a pattern

```shell
# echo -e 'Alice 30\nBob 25\nCharlie 35' | awk '{print $1, $2}'
Alice 30
Bob 25
Charlie 35

# awk -F ':' '{print $1}' /etc/passwd | head -5
root
daemon
bin
sys
sync

# echo -e '10\n20\n30' | awk '{sum += $1} END {print sum}'
60
```

- `awk -F "" -v OFS="" '{print $1}' <file>`
  - `-v` to specify variables, such as `OFS` to set output field separator, `ORS` to set output record separator

- `sed 's/<pattern>/<replacement>/g' <file>`
  - Stream editor for transforming text
  - `-i` to edit a file in place: `sed -i 's/old/new/g' <file>`
  - `sed -n '5,10p' <file>` to print only lines 5 to 10
  - `sed '/^#/d' <file>` to delete comment lines
  - `sed -n '/<pattern>/,/<end>/p' <file>` to print between two patterns

```shell
# echo -e 'Hello World\nFoo Bar' | sed 's/o/0/g'
Hell0 W0rld
F00 Bar

# printf '# comment\nkey=val\n# another\nfoo=bar\n' | sed '/^#/d'
key=val
foo=bar

# printf 'a\nb\nc\nd\ne\nf\ng\n' | sed -n '3,5p'
c
d
e
```

- `cut -d ":" -f 1 <file>`
  - Extract fields from each line using a delimiter. `-d` sets the delimiter, `-f` selects the field(s)
  - `cut -c 1-10 <file>` to extract the first 10 characters of each line
  - `cut -d "," -f 1,3 <file>` to extract multiple fields from a CSV

```shell
# echo 'root:x:0:0:root:/root:/bin/bash' | cut -d ':' -f 1,3
root:0
```

- `tr 'a-z' 'A-Z'`
  - Translate or delete characters
  - `tr -d '\r' < windows.txt > unix.txt` to strip Windows carriage returns
  - `tr -s ' '` to squeeze consecutive spaces into one
  - `tr -cd '[:alnum:]'` to keep only alphanumeric characters

```shell
# echo 'hello world' | tr 'a-z' 'A-Z'
HELLO WORLD

# echo 'hello   world' | tr -s ' '
hello world
```

- `wc <file>`
  - Count lines (`-l`), words (`-w`), or bytes (`-c`) in a file
  - `wc -l <file>` is commonly used to count lines
  - `wc -l *.log` to count lines across multiple files

```shell
# printf 'line1\nline2\nline3\n' | wc -l
3
```

- `uniq -c`
  - Count unique occurrences of consecutive lines. Must be sorted first to count all duplicates
  - `sort <file> | uniq -c | sort -nr` to rank the most frequent lines
  - `-d` to only print duplicate lines, `-u` to only print unique lines

```shell
# printf 'apple\napple\nbanana\ncherry\ncherry\n' | sort | uniq -c | sort -nr
      2 cherry
      2 apple
      1 banana
```

- `sort -nr`
  - Sort lines of text files
  - `-n` sorts numerically, `-r` reverses the order (descending)
  - `-k 2` to sort by the second field: `sort -k 2 <file>`
  - `-t ":" -k 3 -n /etc/passwd` to sort by UID
  - `-u` to remove duplicates after sorting (equivalent to `sort | uniq`)

```shell
# printf '30\n10\n20\n' | sort -n
10
20
30
```

- `head -n 1`/`tail -n 1`
  - Display the first or last line of a file or output
  - `tail -f <file>` to follow a file in real time (useful for log monitoring)
  - `tail -F <file>` to follow even if the file is rotated or recreated

```shell
# printf 'a\nb\nc\nd\ne\n' | head -n 3
a
b
c
```

- `head -c -1`
  - Display all but the last character of a file
- `head -n 173 <file> | tail -n 1`
  - Display only the 173rd line of a file

- `grep <pattern> <file>`
  - `-i` for case-insensitive search, `-w` for whole word match, `-r` for recursive search, `-c` for count of matches, `-n` to show line numbers
  - `-v` to invert the match (show lines that do NOT match)
  - `-l` to show only filenames with matches, `-L` for filenames without matches
  - `-e` to specify multiple patterns: `grep -e "error" -e "warn" <file>`
  - `-o` to print only the matched part of each line
  - `--include="*.log"` to limit recursive search to files matching a glob

```shell
# printf 'error: disk full\ninfo: ok\nwarn: retrying\nerror: timeout\n' | grep -n 'error'
1:error: disk full
4:error: timeout

# printf 'error: disk full\ninfo: ok\nwarn: retrying\nerror: timeout\n' | grep -v 'error'
info: ok
warn: retrying
```

- `grep -A 3 -B 2 <pattern> <file>`
  - Show 3 lines after and 2 lines before each match of the pattern in a file
- `grep -C 4 <pattern> <file>`
  - Show 4 lines of context (before and after) for each match of the pattern in a file
- `grep -c " " <file>`
  - Count non-empty lines in a file (lines containing at least one space character)

- `echo -n <string>`
  - Print a string without a trailing newline
  - `-e` to interpret backslash escapes: `echo -e "line1\nline2"`

```shell
# echo -e "line1\nline2\nline3"
line1
line2
line3
```

- `xargs`
  - Build and execute commands from standard input
  - `find . -name "*.log" | xargs grep "error"` to search across many files
  - `-P 4` for parallel execution: `cat urls.txt | xargs -P 4 -I {} curl -O {}`
  - `-0` to handle filenames with spaces when piped from `find -print0`

```shell
# printf 'file1.txt\nfile2.txt\n' | xargs -I {} echo 'Processing: {}'
Processing: file1.txt
Processing: file2.txt
```

- `tee <file>`
  - Read from stdin and write to both stdout and a file simultaneously
  - `command | tee output.log` to view output while saving it
  - `-a` to append instead of overwrite: `command | tee -a output.log`

```shell
# echo 'some output' | tee output.log
some output
```

### Service Management

- `systemctl <command> <service>`
  - Manage system services
  - Common commands include `start`/`stop`, `restart`, `status`, and `enable`/`disable` (to start on boot)
  - `reload` to reload configuration without a full restart (if the service supports it)
  - `is-active`/`is-enabled` to check a service's state in scripts

- `systemctl daemon-reload`
  - Reload the systemd manager configuration after editing unit files (e.g., after modifying `/etc/systemd/system/`)

- `systemctl list-units --failed`
  - List all failed units
  - `--type=service` to filter only service units
  - `--state=running` to list all currently running services

- `journalctl -u <service> -f`
  - View logs for a specific service managed by systemd, `-f` to follow in real time
  - `-n <lines>` to show the last N lines: `journalctl -u nginx -n 100`
  - `--since "1 hour ago"` / `--until "2026-01-01 12:00:00"` to filter by time range
  - `-p err` to filter by priority (`emerg`, `alert`, `crit`, `err`, `warning`, `notice`, `info`, `debug`)
  - `-b` to show logs only from the current boot
  - `--no-pager` to disable paging, useful for scripting

### Database Management

### Two Pointers

This is often used in problems involving arrays or strings, where we need to find pairs or triplets that satisfy certain conditions. The idea is to use two pointers that move towards each other or in the same direction to reduce the time complexity. Sometimes, it can be three pointers.

#### 15. 3 Sum

> See [LeetCode 15. 3Sum](https://leetcode.com/problems/3sum/).

- Sort the given array if possible to create a predictable order
  - Skip duplicates by comparing with the previous/next element when entering a loop
- The outer loop doesn't have to be the left or right pointer, it can be a fixed pointer with the other two moving towards each other

```python {1,4-5,17-20}
nums.sort()
result = []
for i in range(0, len(nums) - 1):
    if i > 0 and nums[i] == nums[i - 1]:
        continue

    target = -nums[i]
    j = i + 1
    k = len(nums) - 1
    while j < k:
        two_sum = nums[j] + nums[k]
        if two_sum == target:
            result.append((nums[i], nums[j], nums[k]))
            j += 1
            k -= 1

            while j < k and nums[j] == nums[j - 1]:
                j += 1
            while j < k and nums[k] == nums[k + 1]:
                k -= 1
        elif two_sum < target:
            j += 1
        else:
            k -= 1

return result
```

### Sliding Window

A window is a subset of contiguous elements in an array that is defined by two pointers. We focus on expanding and contracting the window for the certain value across the window to find the answer.

#### 424. Longest Repeating Character Replacement

> See [LeetCode 424. Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/).

- Think if the most common/rare value can be compared and stored with `max`/`min` to avoid recalculating

```python {8}
result = 0
left = 0
window = Counter()
most = 0
for right in range(0, len(s)):
    window[s[right]] += 1

    most = max(most, window[s[right]])
    while (right - left + 1) - most > k:
        window[s[left]] -= 1
        left += 1

    result = max(result, right - left + 1)

return result
```

### Binary Search

When the given array is sorted or has a certain order, and the problem requires a `O(log n)` solution, binary search is often a good choice.

#### 33. Search in Rotated Sorted Array

> See [LeetCode 33. Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/).

- Use normal binary search in the correct half, go the other half otherwise

```python {11-14,16-19}
left = 0
right = len(nums) - 1

while left <= right:
    mid = left + (right - left) // 2

    if nums[mid] == target:
        return mid

    if nums[left] <= nums[mid]:
        if nums[left] <= target < nums[mid]:
            right = mid - 1
        else:
            left = mid + 1
    else:
        if nums[right] >= target > nums[mid]:
            left = mid + 1
        else:
            right = mid - 1

return -1
```

#### 34. Find First and Last Position of Element in Sorted Array

> See [LeetCode 34. Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/).

- Can use binary search multiple times to find boundaries
  - When middle equals left or right
  - When there is no more similar element on one side

```python {6-9,22-25}

    return [-1, -1]

        mid = left + (right - left) // 2

        if nums[mid] == target:
            if mid == left or nums[mid - 1] != nums[mid]:
                return mid
            else:
                right = mid - 1
        elif nums[mid] > target:
            right = mid - 1
        else:
            left = mid + 1

    return -1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            if mid == right or nums[mid + 1] != nums[mid]:
                return mid
            else:
                left = mid + 1
        elif nums[mid] > target:
            right = mid - 1
        else:
            left = mid + 1

    return -1

left = 0
right = len(nums) - 1

    if nums[mid] == target:
        break
    elif nums[mid] > target:

    else:
```

#### 74. Search a 2D Matrix

> See [LeetCode 74. Search a 2D Matrix](https://leetcode.com/problems/search-a-2d-matrix/).

- Indices can be virtualized by `m * n`, where `m` is the number of rows and `n` is the number of columns
  - Current row is `index // n`
  - Current column in the row is `index % n`

```python {6,8-9}
m = len(matrix)
n = len(matrix[0])
if m == 0:
    return False

left, right = 0, m * n - 1
while left <= right:
    pivot = (left + right) // 2
    pivot_value = matrix[pivot // n][pivot % n]
    if target == pivot_value:
        return True
    elif target < pivot_value:
        right = pivot - 1
    else:
        left = pivot + 1

return False
```

```python {15,20-24}
        if queue:
            queue.append((-1, -1))
```

### Dynamic Programming

When it comes to finding the maximum/minimum value with previous computations, dynamic programming is often a good choice.

#### 322. Coin Change

> See [LeetCode 322. Coin Change](https://leetcode.com/problems/coin-change/).

##### Top-Down Memoization

- Initialize the DP array with `amount + 1` to make `cache[amount]` more intuitive
- Always cache the minimum value at each step
- The return value can be different from the first time and subsequent times

```python {6-7,15}
def toss(reminder, cache):
    if reminder < 0:
        return -1
    if reminder == 0:
        return 0
    if cache[reminder] != float("inf"):
        return cache[reminder]

    min_cost = float("inf")
    for coin in coins:
        tryout = toss(reminder - coin, cache)
        if tryout != -1:
            min_cost = min(min_cost, tryout + 1)

    cache[reminder] = -1 if min_cost == float("inf") else min_cost
    return cache[reminder]

cache = [float("inf")] * (amount + 1)
return toss(amount, cache)
```

##### Bottom-Up Tabulation

- Increase cost by 1 when needing one or more coins

```python {6-7}
dp = [float("inf")] * (amount + 1)
dp[0] = 0

for current in range(1, amount + 1):
    for coin in coins:
        if current >= coin:
            dp[current] = min(dp[current], dp[current - coin] + 1)

return dp[amount] if dp[amount] != float("inf") else -1
```

### Backtracking

Most backtracking problems can be solved with a very similar template, which is defining a recursive function with a base case and a recursive step iterating choices. In the recursive step, we sometimes need to verify if the current choice is valid or not, and we may need to undo the choice after the recursive backtracking call.

#### 46. Permutations

> See [LeetCode 46. Permutations](https://leetcode.com/problems/permutations/).

- Choices' status can be used as an end condition
- Backtrack (`current.append()` then `current.pop()`) is not always needed if we handle `remaining` properly

```python {4}
result = []

def backtrack(current, remaining):
    if not remaining:
        result.append(current)
        return

    for i in range(0, len(remaining)):
        backtrack(current + [remaining[i]], remaining[:i] + remaining[i + 1:])

backtrack([], nums)
return result
```

#### 78. Subsets

> See [LeetCode 78. Subsets](https://leetcode.com/problems/subsets/).

- Can append the current combination at each step without waiting for the end condition
- Keep in mind that `choices` is changing at each step, hence careful using it as a base case condition

```python {4,6-7,9-12}
result = []

def backtrack(current, choices):
    result.append(current[:])

    if len(current) > len(nums):
        return

    for i in range(0, len(choices)):
        current.append(choices[i])
        backtrack(current, choices[i + 1:])
        current.pop()

backtrack([], nums)
return result
```
