# Design Input Output Verification Validation (DIOVV)

Design Input Output Verification Validation (DIOVV) is a report that provides an audit flow for medical device engineering, manufacturing, and product management teams. The DIOVV report is added to the device master record (DMR), which must be maintained and submitted to the FDA.

## Product Requirements

### Product Requirements Document (PRD)

A PRD defines a product's requirements, including its purpose, features, functionality, and behavior. It serves as a guide for technical and business teams to help build, launch, or market the product.

### Functional Requirements

These requirements specify what the product should do from a user's perspective. They detail the features, functionalities, and interactions necessary to meet user needs.

### Technical Requirements

These requirements refer to how a product is built. They cover the hardware, software, performance, reliability, and security aspects.

## Design Verification (DV)

DV testing is part of the design and development process. It demonstrates that design outputs match design inputs.

## Product Validation

Product validation determines whether the intended purpose is fulfilled and includes usability.

## Verification vs Validation

### Software Testing

Verification ensures that software is built according to design specifications and meets requirements. Validation ensures that software meets user needs and expectations.

### Medical Devices

Verification involves testing a device in a simulated environment to ensure it functions as designed. Validation involves testing the device in a real-world environment to ensure it works as intended.
