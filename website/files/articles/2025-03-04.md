### Above-Average Subarrays

You are given an array `A` containing `N` integers. Your task is to find all subarrays whose average sum is greater than the average sum of the remaining array elements. You must return the start and end index of each subarray in sorted order. A subarray that starts at position L1 and ends at position R1 comes before a subarray that starts at L2 and ends at R2 if `L1 < L2`, or if `L1 = L2` and `R1 ≤ R2`. Note that we'll define the average sum of an empty array to be `0`, and we'll define the indices of the array (for the purpose of output) to be `1` through `N`. A subarray that contains a single element will have `L1 = R1`:

- **Signature**: `int[][] aboveAverageSubarrays(int[] A, int N)`
- **Input**: `1 ≤ N ≤ 2,000`, `1 ≤ A[i] ≤ 1,000,000`
- **Output**: A Subarray that is an object with two integer fields, left and right, defining the range that a given subarray covers. Return a list of all above-average subarrays sorted as explained above

```python
A = [3, 4, 2]
N = 3
aboveAverageSubarrays(A, N)
# Returns [[1, 2], [1, 3], [2, 2]],
# meaning the above-average subarrays are [3, 4], [3, 4, 2], and [4]
```

I implemented a brute force solution first:

```python
def bruteForce(A, N):
    result = []
    for i in range(N):
        for j in range(i, N):
            subarray = A[i:j+1]
            subarray_avg = sum(subarray) / len(subarray)

            if len(subarray) == N:
                result.append([i + 1, j + 1])
                continue

            remaining = A[:i] + A[j+1:]
            remaining_avg = sum(remaining) / len(remaining)

            if subarray_avg > remaining_avg:
                result.append([i + 1, j + 1])
    return result
```

Then optimized it with prefix sums:

```python
def prefixSum(A, N):
    result = []
    prefix = [0] * (N + 1)

    for i, v in enumerate(A):
        prefix[i + 1] = prefix[i] + v

    for i in range(N):
        for j in range(i, N):
            subarray_len = j - i + 1
            remaining_len = N - subarray_len

            if remaining_len == 0:
                result.append([i + 1, j + 1])
                continue

            # We have j + 1 here because we want to include the j value
            # in prefix since prefix[i] = prefix[i - 1] + A[i],
            # and prefix is 1-indexed
            subarray_sum = prefix[j + 1] - prefix[i]
            subarray_avg = subarray_sum / subarray_len
            remaining_avg = (prefix[-1] - subarray_sum) / remaining_len

            if subarray_avg > remaining_avg:
                result.append([i + 1, j + 1])
    return result
```

The optimization reduces the time complexity from `O(N^3)` to `O(N^2)`.

### Answer a Query

Imagine a length-`N` array of booleans, initially all false. Over time, some values are set to true, and at various points in time you would like to find the location of the nearest true to the right of given indices. You will receive `Q` queries, each of which has a type and a value. `SET` queries have type `1` and `GET` queries have type `2`. When you receive a `SET` query, the value of the query denotes an index in the array that is set to true. Note that these indices start at `1`. When you receive a `GET` query, you must return the smallest index that contains a true value that is greater than or equal to the given index, or `-1` if no such index exists:

- **Signature**: `int[] answerQueries(ArrayList<Query> queries, int N)`
- **Input**: A list of `Q` queries, formatted as `[type, index]` where type is either `1` or `2`, and index is `<= N`. `1 <= N <= 1,000,000,000`, `1 <= Q <= 500,000`
- **Output**: Return an array containing the results of all `GET` queries. The result of `queries[i]` is the smallest index that contains a true value that is greater than or equal to `i`, or `-1` if no index satisfies those conditions

```python
N = 5
queries = [[2, 3], [1, 2], [2, 1], [2, 3], [2, 2]]
answerQueries(queries, N)
# Returns [-1, 2, -1, 2],
# the values changes as follows:
# The initial state of the array is [false, false, false, false, false]
# 1st query is GET 3, but no values in the array are true, so the answer is -1
# 2nd query is SET 2, so the value at index 2 is set to true
# The new state of the array is [false, true, false, false, false]
# 3rd query is GET 1, and the index of the true value nearest to 1 (to the right) is 2
# 4th query is GET 3, but no values to the right of index 3 are true
# 5th query is GET 2, and the value at index 2 is true
```

```python
def answerQueries(queries, N):
    states = [False] * N
    result = []

    for type, index in queries:
        index -= 1  # Convert to 0-indexed

        if type == 1:  # SET
            states[index] = True
        else:  # GET
            found = -1
            for j in range(index, N):
                if states[j]:
                    found = j + 1  # Convert back to 1-indexed
                    break
            result.append(found)

    return result
```

### Retrospective

I remembered the interviewer asked my why I used BFS rather than DSF for the graph problem, and I explained that it was actually up to the test cases, and I could switch to DFS if the test cases favored it. I don't think my interviewer was fully convinced, but he let me slide. Most of my energy was spent on the system design and DevOps discussion, which I had to confirm the question several times because there were lots of terminologies I wasn't familiar with. I could relate some of my past experiences, but I had to skip some questions because I had 0 experience as a dedicated system administrator. Again, I think the interviewer understood my background and moved on.

The management discussion was more casual, it first looked like a programming test, but later turned into a discussion about my career goals, expectations, and how I would fit into their team culture. I appreciated the opportunity to ask questions about the company's direction and team dynamics. One thing worth mentioning was that the manager mentioned that they were integrating AI into their products, and as today's date, I see that they have launched some AI-powered features on their website.
