When I was working at [Shopee](https://shopee.tw/) on web-based mobile games, I ran into an interesting challenge while building a backstage for managing game assets like images and audio files. At one point, the marketing team asked for a way to export the current configuration of these assets as JSON files.

To make this happen, I basically needed to simulate a click to download flow in the browser using JavaScript. I hadn't done that before, and the simulation concept was new for me, so it turned into a small side task where I explored the way it works.

<!-- description -->

Prepare a data of type `blob`:

```javascript
const filename = "foo.json";
const data = new Blob([
  JSON.stringify({
    bar: "bar",
    baz: ["qux", "quux"],
  }),
]);
```

Then create an `a` element:

```javascript
const inviableLink = document.createElement("a");
inviableLink.href = URL.createObjectURL(data);
inviableLink.download = filename;
```

Bind the element to a click event:

```javascript
document
  .querySelector("#button-download")
  .addEventListener("click", inviableLink.click);
```

Combine the above to a button element:

```html
<button id="download">Click to Download</button>
<script>
  document.getElementById("download").addEventListener("click", function () {
    const filename = "foo.json";
    const data = new Blob([
      JSON.stringify({
        bar: "bar",
        baz: ["qux", "quux"],
      }),
    ]);
    const link = document.createElement("a");
    link.href = URL.createObjectURL(data);
    link.download = filename;
    link.click();
    URL.revokeObjectURL(link.href);
  });
</script>
```
