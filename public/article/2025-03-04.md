### Above-Average Subarrays

Find all subarrays whose average is greater than the average of the remaining array elements. Return start and end indices (1-indexed) in sorted order.

A subarray starting at L1 and ending at R1 comes before one starting at L2 and ending at R2 if `L1 < L2`, or if `L1 = L2` and `R1 ≤ R2`.

:::note
Empty array average is defined as 0. Indices are 1-based for output.
:::

**Constraints:** 1 ≤ N ≤ 2,000, 1 ≤ A[i] ≤ 1,000,000

```python
Input: A = [3, 4, 2]
Output: [[1, 2], [1, 3], [2, 2]]
# Above-average subarrays: [3, 4], [3, 4, 2], [4]
```

I implemented a brute force solution first, then optimized it with prefix sums:

```python title="Brute Force"
def bruteForce(A):
    result = []
    for i in range(len(A)):
        for j in range(i, len(A)):
            subarray = A[i:j+1]
            subarray_avg = sum(subarray) / len(subarray)

            if len(subarray) == len(A):
                result.append([i + 1, j + 1])
                continue

            remaining = A[:i] + A[j+1:]
            remaining_avg = sum(remaining) / len(remaining)

            if subarray_avg > remaining_avg:
                result.append([i + 1, j + 1])
    return result
```

```python title="Optimized with Prefix Sums"
def aboveAverageSubarrays(A):
    result = []
    prefix = [0] * (len(A) + 1)

    for i, v in enumerate(A):
        prefix[i + 1] = prefix[i] + v

    for i in range(len(A)):
        for j in range(i, len(A)):
            subarray_len = j - i + 1
            remaining_len = len(A) - subarray_len

            if remaining_len == 0:
                result.append([i + 1, j + 1])
                continue

            subarray_sum = prefix[j + 1] - prefix[i]
            subarray_avg = subarray_sum / subarray_len
            remaining_avg = (prefix[-1] - subarray_sum) / remaining_len

            if subarray_avg > remaining_avg:
                result.append([i + 1, j + 1])
    return result
```

The optimization reduces sum calculation from O(n) to O(1) per subarray.

### Answer a Query

Given a boolean array initially all false, handle SET and GET queries efficiently. SET sets an index to true, GET finds the nearest true value to the right of a given index.

Query types: SET (type=1), GET (type=2). Return -1 if no true value exists to the right.

**Constraints:** 1 ≤ N ≤ 1,000,000,000, 1 ≤ Q ≤ 500,000

```python
N = 5, queries = [[2, 3], [1, 2], [2, 1], [2, 3], [2, 2]]
# Output: [-1, 2, -1, 2]
```

Step by step:

1. Initial: `[false, false, false, false, false]`
2. GET 3 → -1 (no true values)
3. SET 2 → `[false, true, false, false, false]`
4. GET 1 → 2 (nearest true from index 1)
5. GET 3 → -1 (no true values right of index 3)
6. GET 2 → 2 (value at index 2 is true)

```python
def answerQueries(queries, N):
    states = [False] * N
    result = []

    for query_type, index in queries:
        index -= 1  # Convert to 0-indexed

        if query_type == 1:  # SET
            states[index] = True
        else:  # GET
            found = -1
            for j in range(index, N):
                if states[j]:
                    found = j + 1  # Convert back to 1-indexed
                    break
            result.append(found)

    return result
```

This maintains a boolean array and performs linear search for GET queries. For the given constraints, a segment tree might be needed for optimal performance.
