While I was solving issues on [Next.js Server Action](/blog/2025-08-01) and [MongoDB Misleading Message](/blog/2025-06-26), I noticed that the WebKit `cog` rendering engine was crashing and flickering regularly on my purpose-built ARM64 board, which was not present on AMD64 Linux and ARM64 macOS, hence I tried to solve it by tuning Next.js and MongoDB setups. However, after resolving the issues mentioned above, I realized that the WebKit issues were still there and needed further investigation.

<!-- description -->

There were two main issues happening regularly:

- Flickering: Some specific components flickered a lot regularly, especially when there were many layers or components on the page
- Crashing: After running for a while, the WebKit process crashed regularly when navigating pages. The console would output message `⨯ [Error: The router state header was sent but could not be parsed.]`

There were some flags I used to launch `cog` to help with mitigating the issues:

- `--web-mem-limit`
- `--disable-web-security`
