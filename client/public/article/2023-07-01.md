Some TypeScript functions that I often use for working with colors, strings, and numbers. These include parsers and convertors from Hex to RGBA, query strings to objects, and Roman numerals to decimals. I haven't figured out a way to verify the input format in a type-secured way. A programmatic check is required for a promised input format.

## Color

Format exchange between color formats and hexadecimal-like formats.

#### Hex to Hexadecimal

This converts a Hex string, such as `ff5733`, to its hexadecimal format `16734003`:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = ""): number => {
    return parseInt(input.replace("#", ""), 16);
  };
  return <code>{parser("#ff5733")}</code>;
}
```

#### RGBA to Hex

This converts an RGBA string, such as `rgba(255, 87, 51, 1)`, to its Hex format `#ff5733`:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = ""): string => {
    const inputMatched: string[] = input.match(
      /^rgba?\s*\(\s*(\d+)\s*,\s*(\d+)\s*,\s*(\d+)\s*(?:,\s*\d+\s*)?\)$/i
    );
    return inputMatched && inputMatched.length === 4
      ? "#" +
          ("0" + parseInt(inputMatched[1], 10).toString(16)).slice(-2) +
          ("0" + parseInt(inputMatched[2], 10).toString(16)).slice(-2) +
          ("0" + parseInt(inputMatched[3], 10).toString(16)).slice(-2)
      : "";
  };
  return <code>{parser("rgba(255, 87, 51, 1)")}</code>;
}
```

#### Hex to RGBA

This converts a Hex string, such as `#ff5733`, to its RGBA format `rgba(255, 87, 51, 1)`:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = "", alpha = 1): string => {
    const inputReplaced = input.replace("#", "");
    const valueRed = parseInt(inputReplaced.substring(0, 2), 16);
    const valueGreen = parseInt(inputReplaced.substring(2, 4), 16);
    const valueBlue = parseInt(inputReplaced.substring(4, 6), 16);
    return `rgba(${valueRed}, ${valueGreen}, ${valueBlue}, ${alpha})`;
  };
  return <code>{parser("#ff5733")}</code>;
}
```

## String

Various string format parsers.

#### Query String

This converts an query string, such as `?foo=bar&bax=qux`, to a its key-value pair object `{"foo":"bar","bax":"qux"}`:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = ""): Record<string, string> => {
    return input
      .substring(1)
      .split("&")
      .reduce((accumulator, currentValue) => {
        const [key, value] = currentValue.split("=");
        accumulator[decodeURIComponent(key)] = decodeURIComponent(value);
        return accumulator;
      }, {} as Record<string, string>);
  };
  return <code>{JSON.stringify(parser("?foo=bar&bax=qux"))}</code>;
}
```

#### JSON in Safe Mode

This ensures errors thrown by `JSON.parse` are retained by returning `null`:

```tsx live
function DemonstrationWrapper() {
  const parser = <T>(input: string): T | null => {
    try {
      return JSON.parse(input);
    } catch (error) {
      return null;
    }
  };
  return <code>{JSON.stringify(parser('{"foo": "bar"}'))}</code>;
}
```

#### Roman Numerals to Decimal

This converts a Roman Numeral, such as `IV`, to its Decimal format `4`:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = ""): number => {
    const mapRoman: Record<string, number> = {
      I: 1,
      V: 5,
      X: 10,
      L: 50,
      C: 100,
      D: 500,
      M: 1000,
    };
    let result = 0;
    for (let i = 0; i < input.length; i++) {
      const current = mapRoman[input[i]];
      const next = mapRoman[input[i + 1]];

      if (next && current < next) {
        result -= current;
      } else {
        result += current;
      }
    }
    return result;
  };
  return <code>{parser("IV")}</code>;
}
```

## Others

Parsers that can't be categorized.

#### CSV to JSON

This converts a CVS string, such as `foo,bar\nbax,qux\nquux,baz`, where `\n` is the line separator and `,` is the field separator, to its JSON format `[{"foo":"bax","bar":"qux"},{"foo":"quux","bar":"baz"}]`, where every element within the array is a row:

```tsx live
function DemonstrationWrapper() {
  const parser = (input = ""): Record<string, string>[] => {
    const [headerLine, ...rowLines] = input.split("\n");
    const headers = headerLine.split(",");
    return rowLines.map((rowLine) => {
      const values = rowLine.split(",");
      return headers.reduce((accumulator, header, index) => {
        accumulator[header] = values[index];
        return accumulator;
      }, {} as Record<string, string>);
    });
  };
  return <code>{JSON.stringify(parser("foo,bar\nbax,qux\nquux,baz"))}</code>;
}
```
