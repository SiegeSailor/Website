---
title: Download JSON Files via HTML
tags: ["HTML", "JavaScript", "JSON"]
---

When I was working at [Shopee](https://shopee.tw/) on web-based mobile games, I ran into an interesting challenge while building a backstage for managing game assets like images and audio files. At one point, the marketing team asked for a way to export the current configuration of these assets as JSON files.

To make this happen, I needed to figure out how to generate and download JSON files directly in the browser using just HTML and JavaScript. I hadn't done that before, so it turned into a small side task where I explored the way it works.

<!-- description -->

To start, prepare the data:

```javascript
const filename = "foo.json";
const data = new Blob([
  JSON.stringify({
    bar: "bar",
    baz: ["qux", "quux"],
  }),
]);
```

Then create an `a` element:

```javascript
const inviableLink = document.createElement("a");
inviableLink.href = URL.createObjectURL(data);
inviableLink.download = filename;
```

Bind the element to a click event:

```javascript
document
  .querySelector("#button-download")
  .addEventListener("click", inviableLink.click);
```

Combine them into one:

```tsx live
function DemonstrationWrapper() {
  return (
    <button
      onClick={() => {
        const filename = "foo.json";
        const data = new Blob([
          JSON.stringify({
            bar: "bar",
            baz: ["qux", "quux"],
          }),
        ]);
        const inviableLink = document.createElement("a");
        inviableLink.href = URL.createObjectURL(data);
        inviableLink.download = filename;
        inviableLink.click();
      }}
    >
      Click to Download
    </button>
  );
}
```
