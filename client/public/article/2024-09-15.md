The first time I worked on a web application was at [Edallianz](https://www.crunchbase.com/organization/edallianz), and dealing with the CSRF token gave me a serious headache. At the time, I had only finished 3 coding courses in my lifetime from [Hex School](https://www.hexschool.com/), a Front-End Development bootcamp, and I barely understood how the browser rendered HTML.

With Django as the backend, I quickly learned that when CSRF protection is enabled, any _POST_, _PUT_, or _DELETE_ request needs to include a valid CSRF token in the headers. Otherwise, the request simply fails.

<!-- description -->

## Retrieve and Use Tokens

The CSRF token is rendered to templates via cookies, allowing templates to access data from Django. However, for asynchronous requests, additional setup is required to include CSRF tokens in the request headers. This section explains different methods on how to retrieve tokens from cookies.

### Universal Cookie

First, install the package via NPM:

```shell
npm install --save \
    universal-cookie
```

Next, import it into the JavaScript file where the cookies will be accessed.

```javascript
import cookies from "universal-cookie";
```

To use the CSRF token:

```javascript
fetch("/foo/bar", {
  method: "POST",
  headers: {
    "X-CSRFToken": cookies.get("csrftoken"),
  },
});
```

:::warning

Note that `csrftoken` is not available on this website since it is not rendered by a Django framework. This warning is here because some people might try to run the code on this page.

:::

### Document Cookie

CSRF token can be retrieved by parsing `document.cookie` without third-party packages:

```jsx live
function DemonstrationWrapper() {
  const cookies = document.cookie.split(";").reduce((current, accumulator) => {
    const [key, value] = accumulator.trim().split("=").map(decodeURIComponent);
    try {
      return Object.assign(current, { [key]: JSON.parse(value) });
    } catch (error) {
      return Object.assign(current, { [key]: value });
    }
  }, {});
  return <code>{JSON.stringify(cookies)}</code>;
}
```

To use the CSRF token:

```javascript
fetch("/foo/bar", {
  method: "POST",
  headers: {
    "X-CSRFToken": cookies["csrftoken"],
  },
});
```

Or, when waiting for `n` cookie keys to be fully parsed is expensive:

```javascript
function getCookie(name) {
  const cookieString = document.cookie;
  const cookies = cookieString.split(";");
  for (let i = 0; i < cookies.length; i++) {
    const cookie = cookies[i].trim();
    if (cookie.startsWith(`${name}=`)) {
      return decodeURIComponent(cookie.substring(name.length + 1));
    }
  }
  return null;
}
```

To use the CSRF token:

```javascript
fetch("/foo/bar", {
  method: "POST",
  headers: {
    "X-CSRFToken": getCookie("csrftoken"),
  },
});
```

:::warning

Note that `csrftoken` is not available on this website since it is not rendered by a Django framework. This warning is here because some people might try to run the code on this page.

:::
