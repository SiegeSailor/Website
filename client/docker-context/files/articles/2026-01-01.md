## SadServers

I tested the following commands using a Docker container with the `ubuntu:22.04` image. Some tools require additional installation:

```shell
docker run \
  --rm --interactive --tty \
  --privileged \
  ubuntu:22.04 bash -c "
    apt-get update &&
    apt-get install --yes sysstat nmap &&
    exec bash"
```

### System Monitoring

| Command           | Description                                                                                                                                                                                                |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `uptime`          | Total load average over 1/5/15 minutes                                                                                                                                                                     |
| `dmesg \| tail`   | Watch for the error messages. Always check this since the messages are clear indicators                                                                                                                    |
| `vmstat 1`        | Watch `r` for running processes and `us` for user CPU usage                                                                                                                                                |
| `mpstat -P ALL 1` | List CPU usage per processor                                                                                                                                                                               |
| `pidstat 1`       | List CPU usage per process. A 1600 `%CPU` means the process takes 16 cores fully loaded                                                                                                                    |
| `iostat -xz 1`    | Watch too-high `r/s`, `w/s`, `await` for excessive load, >1 `avgqu-sz` for being saturated, >60% `%util` for being too busy. This is not a strong indication as many techniques perform I/S asynchronously |
| `free -m`         | RAM. Safe as long as they are non-zero, which can lead to higher disk I/O (confirm using `iostat -xz 1`). Free memory can include buffers/cache which can be reclaimed quickly when needed                 |
| `top`             | Just everything                                                                                                                                                                                            |
| `ps auxf`         | Display running processes. `a` shows processes for all users, `u` displays the process's user/owner, `x` shows processes not attached to a terminal, and `f` displays a tree view of processes             |

### Network Diagnostics

| Command                  | Description                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ping -W 1 -c 1 8.8.8.8` | Test network connectivity by sending a request to Google's DNS server. Fail if no response (`-c`) is received within 1 second (`-W`)                   |
| `sar -n DEV 1`           | Network interface throughput. Watch `rxkB/s` (received KB/s) and `txkB/s` (transmitted KB/s) especially                                                |
| `sar -n TCP,ETCP 1`      | TCP metrics. See `active/s` for locally initialized connections, `passive/s` for remote connections, `retrans/s` for retransmissions                   |
| `netstat -tulpn`         | Show active listening ports and associated programs. `-t` for TCP, `-u` for UDP, `-l` for listening, `-p` for program name, `-n` for numeric addresses |
| `nc -zv <start>-<end>`   | Scan open ports in a given range. `-z` for scanning without sending data, `-v` for verbose output                                                      |
| `nmap -p - localhost`    | Scan all 65535 TCP ports on localhost, where `-` represents the full range of ports (1-65535)                                                          |

### Text Processing

| Command                                       | Description                                                                                                                                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `awk '{print $1}' <file>`                     | Extract the first column from a file or command output, separating fields by whitespace (use `-F` for a different delimiter)                                                         |
| `awk -F "" -v OFS="" '{print $1, $2}' <file>` | `-v` to specify variables, such as `OFS` to set output field separator, `ORS` to set output record separator                                                                         |
| `uniq -c`                                     | Count unique occurrences of lines in a file                                                                                                                                          |
| `sort -nr`                                    | Sort lines of text files. `-n` sorts numerically, `-r` reverses the order (descending)                                                                                               |
| `head -n 1` / `tail -n 1`                     | Display the first or last line of a file or output                                                                                                                                   |
| `head -c -1`                                  | Display all but the last character of a file                                                                                                                                         |
| `head -n 173 <file> \| tail -n 1`             | Display only the 173rd line of a file                                                                                                                                                |
| `grep <pattern> <file>`                       | `-i` for case-insensitive search, `-w` for whole word match, `-r` for recursive search, `-A`, `-B`, and `-C` for context lines, `-c` for count of matches, `-n` to show line numbers |
| `grep -c " " <file>`                          | Count non-empty lines in a file (lines containing at least one space character)                                                                                                      |
| `echo -n <string>`                            | Print a string without a trailing newline                                                                                                                                            |

## LeetCode

I only focus on problems that can be solved with specific techniques.

### Two Pointers

This is often used in problems involving arrays or strings, where we need to find pairs or triplets that satisfy certain conditions. The idea is to use two pointers that move towards each other or in the same direction to reduce the time complexity. Sometimes, it can be three pointers.

#### 15. 3 Sum

> See [LeetCode 15. 3Sum](https://leetcode.com/problems/3sum/).

- Sort the given array if possible to create a predictable order
  - Skip duplicates by comparing with the previous/next element when entering a loop
- The outer loop doesn't have to be the left or right pointer, it can be a fixed pointer with the other two moving towards each other

#### 11. Container With Most Water

> See [LeetCode 11. Container With Most Water](https://leetcode.com/problems/container-with-most-water/).

- Can move both pointers accordingly

#### 3. Longest Substring Without Repeating Characters

> See [LeetCode 3. Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/).

- Store pointer positions in a hash map for quick lookup

### Sliding Window

A window is a subset of contiguous elements in an array that is defined by two pointers. We focus on expanding and contracting the window for the certain value across the window to find the answer.

#### 424. Longest Repeating Character Replacement

> See [LeetCode 424. Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/).

- Think if the most common/rare value can be compared and stored with `max`/`min` to avoid recalculating

### Binary Search

When the given array is sorted or has a certain order, and the problem requires a `O(log n)` solution, binary search is often a good choice.

#### 33. Search in Rotated Sorted Array

> See [LeetCode 33. Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/).

- Use `>=` and `<=` because the target can be equal to the left, right, or middle element
- Use normal binary search in the correct half, go the other half otherwise

#### 34. Find First and Last Position of Element in Sorted Array

> See [LeetCode 34. Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/).

- Can use binary search multiple times to find boundaries
  - When middle equals left or right
  - When there is no more similar element on one side

#### 74. Search a 2D Matrix

> See [LeetCode 74. Search a 2D Matrix](https://leetcode.com/problems/search-a-2d-matrix/).

- Indices can be virtualized by `m * n`, where `m` is the number of rows and `n` is the number of columns
  - Current row is `index // n`
  - Current column in the row is `index % n`
