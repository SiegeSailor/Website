During deployment, different environments often require different environment variables. Although frameworks typically support separating Local and Production environments, if you need additional environments like UAT or Staging, you'll need a tool that can specify environment variables for specific environments.

At this point, besides native Shell Script syntax, there's another option, `env-cmd`.

<!-- description -->

## Usage

Assuming `.env` exists outside the root folder with the following content:

```shell title="./configuration/.env"
EXAMPLE_ENV=1
```

When executing, you can use the following command to set this .env file as the default environment variable source:

```shell
env-cmd -f ./configuration/.env npm run build
```

## Practical Use in React Projects

According to [CRA What Other Dot Env Files Can Be Used](https://create-react-app.dev/docs/adding-custom-environment-variables/), the default supported .env files can be divided into three levels: `.test`, `.local`, and `.development` or `.production`. This means that if you use deployment methods like Firebase Hosting that deploy directly from local, you cannot correspond to more than two environments simultaneously.

Assume we have the following three environment variable files:

```shell title=".env.development"
REACT_APP_IS_DEBUG=true
REACT_APP_TITLE="Development Environment"
```

```shell title=".env.uat"
REACT_APP_IS_DEBUG=true
REACT_APP_TITLE="UAT Environment"
```

```shell title=".env.production"
REACT_APP_IS_DEBUG=false
REACT_APP_TITLE="Production Environment"
```

Combined with NPM Scripts and `env-cmd`, you can manually point to environment variables:

```json title="package.json"
{
  "scripts": {
    "host-uat": "env-cmd -f .env.uat npm run build && firebase deploy --only hosting:uat",
    "host-prod": "env-cmd -f .env.production npm run build && firebase deploy --only hosting:production"
  }
}
```

:::note
Note that `&&` in NPM Scripts means execute together. The `firebase deploy` here is used for Firebase Hosting and is not required.
:::
