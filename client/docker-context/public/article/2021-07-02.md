When using CLI or writing Shell Scripts, you often need to replace values in a script or certain strings with environment variables. If you directly use commands like `find` and `replace` to operate, it will be quite burdensome.

At this point, besides native Shell Script syntax, there's another option: `envsubst`.

<!-- description -->

## Using with GitLab CI/CD

```yml
image: node:13.10.1

stages:
  - build

build:
  before_script:
    - apt-get update; apt-get install gettext-base git -y
  script:
    - mv .env .env.tmp; envsubst < .env.tmp > .env
    - npm ci --allow-root
    - npx patch-package
```

## Usage

First, let's export an environment variable:

```shell
export EXAMPLE_ENV="Happy"
```

Next, create a file `example.conf` and enter the following content:

```conf title="example.conf"
I am ${EXAMPLE_ENV}.
```

Then execute the following command:

```shell
envsubst < example.conf
```

If you need to save the replaced content, simply use the native Shell Script `>` operator:

```shell
envsubst < example.conf > replaced.conf
```

`replaced.conf` will have the following content:

```conf title="replaced.conf"
I am Happy.
```

## Troubleshooting

If the Terminal returns _envsubst: Command not found_, it's because `envsubst` is part of `gettext`, and you haven't installed either yet. You can refer to the Stack Overflow discussion on "How to install gettext on macOS X" for this.

Use the following command to install `gettext`:

```shell
brew install gettext
brew link --force gettext
```

When executing `brew install gettext`, you might encounter _Error: Permission denied_. Intuitively, we would use `sudo` to solve this, however, because Homebrew strictly prohibits using Super Permissions to manage packages, we need to use other methods to resolve this. For example, `chown`:

```shell
sudo chown -R "$USER":admin /usr/local
chown -R "$USER":admin /Library/Caches/Homebrew
```

On macOS High Sierra, you cannot use `chown` within `/usr/local` directly, so you must use some indirect methods:

```shell
#!/bin/bash
sudo chown -R $(whoami) $(brew --prefix)/*
```

```shell
#!/bin/fish
sudo chown -R (whoami) (brew --prefix)/*
```
